## New specs needed (8 stories → 1 combined spec + 6 individual specs)

The following are ABSENT from grostak-v2 and require new specs. I'm grouping where logical:

### Spec A — Patient profile extended fields (STORY-003 + STORY-004)

Two patient profile gaps that share the same schema migration:

- **STORY-003**: `PATCH /patients/me/profile` needs `medicalDisclaimerAcceptedAt`, `privacyPolicyAcceptedAt`, `termsAcceptedAt` fields (currently stored in Clerk `unsafeMetadata` — must move server-side)
- **STORY-004**: `sex` and `dateOfBirth` fields on Patient model + accept via PATCH

Patient schema has none of these fields today. Single migration adds all 5 columns. Single spec covers both stories.

### Spec B — Weight log endpoint (STORY-056)

Dedicated `POST /patients/me/weight-logs` + `GET` endpoint. No WeightLog model in schema. Currently piggybacked on check-ins with `protocolId: "weight-log"` hack.

### Spec C — Clerk-proxied account management (STORY-058 + STORY-059)

`PATCH /patients/me/email` and `PATCH /patients/me/password` — both route through grostak-v2 which calls Clerk Backend API server-side. Hard constraint confirmed: patient never touches Clerk directly. These are closely related and can be one spec.

### Spec D — Per-protocol reminder storage (STORY-061)

Store per-protocol reminder times on the Protocol assignment (or a separate ReminderConfig model). Scheduling/delivery infra depends on UC-X01 notifications (currently ABSENT — zero infra). Spec can define the storage layer; scheduling is blocked until notifications ship.

### Spec E — Account deletion (STORY-064)

`DELETE /patients/me` — soft-delete patient record, revoke Clerk user, delete all associated data per retention policy. App Store compliance blocker. Requires Clerk Backend API call server-side.

### Spec F — Patient data export (STORY-073)

CCPA/CPRA hard constraint. Export all patient data as JSON/CSV, deliver via email. No export infrastructure exists anywhere. Depends on email sending infrastructure (AWS SES — covered under AWS BAA once that pre-launch gate is cleared).
